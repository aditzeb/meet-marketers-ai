# Meet Marketers AI — Brand Assets

This directory contains the official logo assets for Meet Marketers AI.

## Files
- `meet_marketers_logo.png` — High-resolution Meet Marketers AI primary logo.
- `logo.png` — Compact app icon / mark.

## Customization
To use your own custom logo, simply replace `meet_marketers_logo.png` or `logo.png` in this folder. The Flutter app automatically loads this asset with rounded corners and graceful fallback support.
